Palette + type

Desktop teal #18746F, system grey #C5C5BF, title blue #00067C, yellow highlight. Courier New gives game flavor; Arial keeps dialogs and controls readable.

Imagery + texture

Portraits use an intentional low-color preview with the approved full source retained separately. Bevels, dithering and pixels frame the window; table lines stay smooth and accurate.

Motion + audio

Windows snap rather than float; progress bars communicate real wait states. Button click, menu tick and game sounds have separate volume, captions, mute and reduced-motion behavior.

Layout + access

Portrait reads like a character dialog; landscape resembles a game window. Mobile buttons keep 44px minimum despite compact styling; focus uses a thick dotted plus color outline.

Communicates well

A playful, ownable game artifact with obvious controls, visible save language and room for hidden files/Easter eggs later.

Fails when

Tiny UI mimics desktop pixels literally; modal windows block balls; skeuomorphism slows common actions; parody overwhelms the personal pub memory.

Recovery states

U02 becomes a truthful save progress window; X02 keeps “Continue current session” active. R03 names the retained save and compatible-version option without fake technical detail.

Phone question

Does the interface feel tactile and period-right while every action remains comfortably tappable and the G01 table still feels like the main application?
