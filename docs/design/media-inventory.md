## Asset conventions

Keep original source and derived crop separate when assets arrive. For every imported asset record creator, source URL/file, rights, intended visibility, transformations, alternative text/caption, and fallback. Do not publish real personal media before its intended use is established. Boards may cite period references as inspiration without copying their assets.

Label placeholders in the artifact itself, not just in this inventory. Missing portraits use silhouettes/initials; missing sound is silent with caption text; missing decorative textures use solid colors. Core table geometry must remain understandable with all optional media absent.
