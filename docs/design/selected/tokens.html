Concrete visual, layout, behavior, photo, and accessibility notes for a future prototype agent. These tokens describe the mockup, not production code or settled pool rules.

Design job

The phone must make a direct pool shot feel obvious and satisfying while always reading as a 1998 sports broadcast of friends playing inside the Grenadier. The next action is usually to touch the table, resume the one saved live match, skip a handover, or intentionally start a fresh rack.

Selective pixel treatment

Portraits are recognisable pixel-art caricatures, not plain photo crops. C1 exaggerates smiles and head shapes using stepped pixel clusters. Pixel texture may also appear in pub cutaways, table materials and brief broadcast transitions; aiming lines, cue-contact feedback and text retain clear edges. Sports Broadcast remains the main visual language. This is a first likeness/style sample, not final character art.

Component rules

Table first

  • Use the entire available play viewport, preserving table ratio.
  • No permanent right rail or bottom control deck.
  • Score and turn captions hug safe rails, not ball paths.
  • Do not pan or zoom during aim or motion.

Touch state

  • On contact, nonessential chrome fades toward 26%.
  • Armed status and same-finger abort remain fully opaque.
  • Never move the aim target under the active finger.
  • All interruption paths disarm without shooting.

Cue contact

  • Expand the cue ball into a remote popover away from the touch.
  • Show crosshairs and a visible contact dot for spin/backspin.
  • Announce position textually: center, high, low, left, right.
  • The exact combination with orbit/power needs touch testing.

Captions

  • Opaque navy base, red live edge, gold state highlight.
  • One message per caption; dismiss when understood.
  • Use plain verbs: Aiming, Armed, Abort, Pot, Foul.
  • Foul/two-shot/early-black semantics remain undefined.

Friends photo

  • Use the generated C1 pixel-art caricature study; keep the supplied original as reference.
  • Preserve all four identities; names remain live readable text.
  • Names left to right: Trod, Craig, Shacka, Maaaaark.
  • No traits, teams, or individual personalities have been assigned.

Pub cutaway

  • Optional and skippable after balls settle.
  • Table left of a back-wall bar; entrance above bar, toilets left/right; social seating on both sides, no second table.
  • Original CSS/SVG 2.5D spatial placeholder; use the canonical schematic plan for layout.
  • Betty is a named stern landlady cameo with no supplied likeness.

Match + final

  • Only one live active match; it may remain turn-based for a long time.
  • Resume restores that match and does not imply a concurrent inbox.
  • Z01 knockabout never changes the final result.
  • Re-rack is an explicit fresh start.

Formats

  • Both 2 v 2 and winner-stays-on are desired.
  • Team order, fouls, two-shots, early-black, queues, and 50p meaning are unresolved.
  • Show the 50p motif only as future flavor, never payment UI.
  • No timeout/forfeit behavior is defined.

Motion + sound

  • Pool contacts lead; use the companion sound artifact.
  • Motion communicates state change, never decoration.
  • Reduce motion: static cut between states and keep turn text.
  • Reduced transparency: use fully opaque captions.

Accessible non-drag path

A clearly named “Shot controls” action may open a separate sheet with 44px controls for cue angle, power, cue-contact point, Preview, Abort, and Play shot. Keyboard mapping may use arrows for angle, Shift+arrows for power/contact, Escape to abort, and Enter to play only after an explicit armed state. This route is an accessibility proposal and must preserve the same game state; it does not replace direct one-finger play.

Reduced motion and transparency

With reduced motion, G05 becomes a static pub/location card and immediately returns to the same top-down table. With reduced transparency or increased contrast, score, armed, abort, and feedback fields use solid navy/red backgrounds; no state depends on translucency.

Verification checklist

  • Portrait layout reviewed at 390×844.
  • Landscape layout reviewed at 844×390.
  • Compact pressure check at 320×568.
  • 2:1 / 1:2 table geometry measured in browser.
  • Six pockets occupy corners and long-rail midpoints.
  • Original photo is preserved; C1 derivation and prompt are recorded.
  • Critical text contrast meets WCAG AA target.
  • Armed and abort remain legible during touch.
  • pointercancel returns mockup to G01.
  • No physical iPhone or Android device claim is made.

Safe simplifications for the prototype

A prototype may use circles for balls, a flat top-down table, static captions, the system type fallbacks above, a still pub card instead of G05, and deterministic object positions. It must preserve table geometry, cue orbit visibility, the away-from-touch contact control, same-finger abort, interruption disarm, one-live-match wording, and a separate final/knockabout state.
